## Products I built · in production

| Product | What it does | Stack |
|---|---|---|
| **Base** *(building now)* | Multi-tenant SaaS platform: authentication, organizations & roles, subscription billing, secure file storage and admin panel, exposed as an API any product can plug into | Go · PostgreSQL · AWS |
| **Wemei** | ERP for Brazilian micro-entrepreneurs: tax filings, invoicing, financial control, payment integration, subscription billing | Go · PostgreSQL · AWS · Next.js |
| **Patrify** | Personal wealth management: portfolio tracking across asset classes, PDF reports, AI-assisted suggestions, real-time metrics | Go · PostgreSQL · AWS · Next.js |
| **Unboxfiscal** | Digital business address: encrypted document upload, per-unit access control, multi-tenant admin | Go · PostgreSQL · AWS · Next.js |

Base was extracted from the parts that kept repeating across the other three: every product needed the same auth, tenants, billing and admin, so I turned them into one platform.
