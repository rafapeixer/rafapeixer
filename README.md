## 🚀 Products I've built (in production)

| Product | What it does | Stack |
|---|---|---|
| **Base** *(building now)* | Multi-tenant SaaS platform: auth, organizations & roles, billing, file storage, admin panel, exposed as an API for any product to plug into | Go · PostgreSQL · AWS |
| **Wemei** | ERP for Brazilian micro-entrepreneurs: tax filings, invoicing, financial control, subscription billing | Go · PostgreSQL · AWS · Next.js |
| **Patrify** | Personal wealth management: portfolio tracking across asset classes, PDF reports, AI-assisted suggestions | Go · PostgreSQL · AWS · Next.js |
| **Unboxfiscal** | Digital business address service: encrypted document upload, per-unit access control, multi-tenant admin | Go · PostgreSQL · AWS · Next.js |

Base was born from the parts that kept repeating across the other three: every product needed the same auth, tenants, billing and admin. So I extracted them into one platform.
